# PetCare AI

Aplicación web desarrollada con Node.js, Express, Supabase, Google Maps API y Gemini AI para el registro de mascotas, visualización de establecimientos y consulta asistida por IA.

## Estructura del proyecto
- `package.json`: dependencias y scripts de inicio.
- `server.js`: servidor Express y rutas de configuración y chat con Gemini.
- `public/index.html`: interfaz principal de la aplicación.
- `public/styles.css`: estilos visuales.
- `public/app.js`: lógica del cliente, conexión con Supabase, mapa y chat.

## Variables de entorno
- `SUPABASE_URL`
- `SUPABASE_KEY`
- `GEMINI_API_KEY`
- `GOOGLE_MAPS_API_KEY`
